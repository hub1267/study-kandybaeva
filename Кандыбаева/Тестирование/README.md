## Автотесты

Для Selenium необходимы Python, пакет из `requirements.txt`, браузер Chrome и совместимый ChromeDriver (Selenium Manager обычно находит драйвер автоматически при доступе к сети).

1. Создать и заполнить базу из каталога `МДК_04_01/База_данных`.
2. Запустить `python3 server.py` в каталоге приложения.
3. В каталоге тестирования установить зависимости и запустить:

```sh
python3 -m pip install -r requirements.txt
python3 -m unittest discover -s tests -v
```

В тестах используются Page Object, явные ожидания и скриншот при падении. Тесты предусмотрены для отдельной учебной базы с заказом № 1; они не удаляют данные.

Конфигурация GitHub Actions находится в корне удалённого репозитория по пути `.github/workflows/smoke.yml`; `ci-example.yml` содержит её копию.
