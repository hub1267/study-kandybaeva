# Проверка портала с Puppeteer

Установите Node.js и Chrome, запустите портал на порту 8001, затем выполните:

```sh
npm ci
CHROME_PATH="/путь/к/Chrome" npm test
```

Тест открывает страницу, проверяет заголовок, входит как учебный администратор и проверяет отображение списка заявок. `APP_URL` позволяет указать другой адрес приложения.
