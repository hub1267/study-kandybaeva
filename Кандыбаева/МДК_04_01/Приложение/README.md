# Учебное приложение магазина обуви

Выполнил: Бокун Алексей Янович. Группа: 4ИСП9-45.

Реализованы части практических работ 2.1 (HTTP-сервер), 2.2 (поиск пользователя по логину), 2.5 (каркас страницы), 3.1 (список заказов) и 3.2 (редактирование заказа).

## Запуск

1. В соседней папке «База_данных» выполнить `python3 create_db.py` и один раз загрузить `demo_data.sql` в созданную `shop.db`, как описано в README этой папки.
2. В текущей папке выполнить `python3 server.py`.
3. Открыть в браузере http://127.0.0.1:8000/. Для панели заказов использовать учебный логин `manager` или `admin`.

Администратор может изменить дату заказа и убрать позицию; после сохранения её количество возвращается на склад в одной транзакции. Менеджер может просматривать состав заказа.

**Ограничение учебной модели:** вход выполнен только по логину по формулировке практической работы; проверка роли действует только в интерфейсе, сервер не проверяет личность. Данное приложение предназначено исключительно для локальной демонстрации на учебных данных и не является защищённой системой. Для реального доступа нужны пароли, сессии и серверная проверка прав.
