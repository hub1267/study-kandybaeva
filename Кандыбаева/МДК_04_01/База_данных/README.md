# Практические работы 1.2, 1.3 и 1.10

Тема: магазин обуви. Данные в `demo_data.sql` учебные и созданы для проверки запросов; это не файлы преподавателя.

## 1.2 Создание схемы БД

`schema.sql` создаёт восемь таблиц, первичные и внешние ключи, ограничения UNIQUE и CHECK, каскадное удаление зависимых позиций и индексы. В SQLite контроль внешних ключей необходимо включать для каждого подключения командой `PRAGMA foreign_keys = ON`.

```sh
sqlite3 example.db < schema.sql
sqlite3 example.db '.tables'
```

Ожидаемые таблицы: categories, manufacturers, products, sizes, stock, users, orders и order_items.

## 1.3 Создание БД из Python

```sh
python3 create_db.py
```

Программа создаёт `shop.db` рядом со скриптом и выводит список таблиц из `sqlite_master`. Скрипт пишет диагностическое сообщение и завершает работу с кодом 1 при ошибке. Повторный запуск не удаляет содержимое существующих таблиц.

## 1.10 Запросы

На новой базе можно загрузить учебные записи и запустить восемь запросов:

```sh
sqlite3 example.db < demo_data.sql
sqlite3 -header -column example.db < queries.sql
```

Загрузку демонстрационных данных выполняют один раз. Для повторного примера создайте новую базу. Запросы показывают фильтрацию, группировку, JOIN и NOT EXISTS. Скидка рассчитывается по отсутствию заказов в предыдущем календарном месяце; цена в заказе сохраняется отдельно от текущей цены товара.

## Подготовка к сдаче

Проверка выполнена в текущей среде macOS. Для отчёта преподавателя нужно запустить команды в ROSA Linux и добавить собственные скриншоты терминала. Исходные скрипты служат листингами; формат и контрольные вопросы следует уточнить у преподавателя. Не выдавайте учебные данные за файлы импорта из КИМ.
