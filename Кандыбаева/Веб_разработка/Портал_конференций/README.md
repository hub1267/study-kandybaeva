# Учебный портал конференций

Проект объединяет работы по проектированию и разработке веб-приложений. Используются Python 3, SQLite, HTML, CSS и JavaScript без сторонних библиотек.

## Запуск на Mac

Из папки проекта:

```sh
python3 server.py
```

Откройте http://127.0.0.1:8001/. При первом запуске создаётся база `conference.db` и учебные мероприятия. Создайте аккаунт участника через форму. Учебный администратор: логин `admin`, пароль `Admin12345`.

Гость видит мероприятия, участник может зарегистрироваться, войти, подать заявку и посмотреть её. Администратор просматривает и фильтрует заявки, переводит статус вперёд. Участник может оставить отзыв после завершения мероприятия и обработки заявки. Тестовое мероприятие с прошедшей датой позволяет проверить отзыв.

Для варианта «Техфорум» с отдельной учебной базой и другим оформлением:

```sh
PORTAL_THEME=tech PORT=8002 python3 server.py
```

Затем откройте http://127.0.0.1:8002/. Данные и учётные записи двух вариантов не смешиваются.

## Проверка API

```sh
python3 -m unittest discover -s tests -v
```

Тест создаёт отдельную временную базу и проверяет регистрацию, вход, заявку, разграничение прав, смену статусов, отзыв и выход.

## Ограничения

Это учебный локальный проект, не готовый для размещения в интернете. Данные мероприятий и учётная запись администратора — учебные. Вместо MySQL используется SQLite; схема и данные не мигрированы в MySQL. Для публикации потребуются HTTPS с Secure-cookie, настройка защиты от перебора и полноценная эксплуатационная конфигурация.
