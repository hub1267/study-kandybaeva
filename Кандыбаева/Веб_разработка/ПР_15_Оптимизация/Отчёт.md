# Оптимизация кода

Выполнил: Бокун Алексей Янович. Группа: 4ИСП9-45.

## Результат

Созданы минифицированные версии JavaScript и CSS с помощью esbuild; страница использует эти версии, исходники сохранены отдельно. Для заявок созданы индексы по пользователю и статусу. Для оценки скорости под нагрузкой требуются отдельные измерения.

Исходный код и инструкция запуска находятся в соседней папке «Портал_конференций». Иллюстрация в этой папке снята с работающего учебного приложения на Mac.
