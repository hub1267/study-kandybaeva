# Разработка интерфейса пользователя

Выполнил: Бокун Алексей Янович. Группа: 4ИСП9-45.

## Результат

Интерфейс построен на HTML, CSS и JavaScript, содержит список мероприятий, вход, регистрацию и заявки. Адаптивность проверена в Chrome с эмуляцией 390 × 844; в Firefox дополнительно проверены открытие портала, вход администратора и список заявок.

Исходный код и инструкция запуска находятся в соседней папке «Портал_конференций». Иллюстрация в этой папке снята с работающего учебного приложения на Mac.
