## Источник

Для проекта без стороннего фреймворка использована локальная справка Python: модули `http.server` и `sqlite3`. Текст справки сохранён в `справка.txt`; получить его повторно можно командами `python3 -m pydoc http.server` и `python3 -m pydoc sqlite3`.

## Анализ и исправления

- При проверке интерфейса у участника отображался фильтр, предназначенный для администратора. Причина — CSS-правило `label { display: block }` перекрывало действие атрибута `hidden`. Добавлено правило `[hidden] { display: none !important; }`.
- Тестирование уникальности логина и заявки вызывает ошибку ограничения SQLite. Сервер перехватывает `sqlite3.IntegrityError` и возвращает HTTP 409 с сообщением, вместо аварийного завершения обработки запроса.
- Программа создаёт базу при первом запуске; при обновлении старой базы добавляет недостающие столбцы. Интеграционный тест проверяет сохранение существующей записи.

Историю изменений проекта можно просмотреть командой `git log --oneline` в корне репозитория.
