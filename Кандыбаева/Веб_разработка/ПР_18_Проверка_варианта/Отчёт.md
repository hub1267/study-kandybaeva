# Проверка вариативной части

Выполнил: Бокун Алексей Янович. Группа: 4ИСП9-45.

## Результат

В Chrome открыта версия «Техфорум», создана учебная учётная запись, выполнен вход и отправлена заявка. Созданная заявка отображается в личном кабинете. Остальные функции варианта используют общие с основным порталом модули; отдельно весь функционал варианта ещё не проверялся.

Исходный код и инструкция запуска находятся в соседней папке «Портал_конференций». Иллюстрация в этой папке снята с работающего учебного приложения на Mac.
