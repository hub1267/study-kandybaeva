# Доработка структуры базы данных

Выполнил: Бокун Алексей Янович. Группа: 4ИСП9-45.

## Результат

Добавлены поля оплаты и помещения в заявки; при запуске выполняется добавление отсутствующих полей с сохранением старых записей. Тест создаёт старую структуру, запускает миграцию и проверяет сохранённую запись. Схема выполнена для SQLite, не MySQL.

Исходный код и инструкция запуска находятся в соседней папке «Портал_конференций». Иллюстрация в этой папке снята с работающего учебного приложения на Mac.
