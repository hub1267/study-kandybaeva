# Разработка веб-приложения

Выполнил: Бокун Алексей Янович. Группа: 4ИСП9-45.

## Результат

Интерфейс взаимодействует с HTTP API и SQLite. Участник создаёт и отменяет новую заявку, администратор последовательно изменяет её статус; после завершения заявки и мероприятия участник может оставить отзыв.

Исходный код и инструкция запуска находятся в соседней папке «Портал_конференций». Иллюстрация в этой папке снята с работающего учебного приложения на Mac.
