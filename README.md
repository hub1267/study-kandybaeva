# Учебные работы

Черновик учебных материалов по МДК 04.01, тестированию информационных систем и веб-разработке.

- `Кандыбаева/МДК_04_01` — база и учебное приложение магазина обуви.
- `Кандыбаева/Тестирование` — тестовая документация и Selenium-тесты.
- `Кандыбаева/Веб_разработка` — учебный портал конференций, вариант «Техфорум», практические работы и скриншоты.
- `Кандыбаева/СТАТУС.md` — что подготовлено и что ещё нужно сделать.

Работа продолжается: материалы ещё не являются полным комплектом для сдачи. Тестовые данные вымышлены. Приложение магазина предназначено для локальной демонстрации и не обеспечивает полноценную авторизацию.

Тесты Selenium запускаются автоматически через GitHub Actions, а также локально по инструкции в папке тестирования. Для преподавателя требуется отдельно согласовать доступ к закрытому репозиторию.
